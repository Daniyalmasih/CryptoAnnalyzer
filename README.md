# CryptoAnalyzer - Binance Futures Market Analysis Terminal

A professional-grade terminal application for analyzing Binance Futures markets with real-time data visualization, whale detection, and multi-factor analysis.

## Features

- **Order Book Analysis**: 1000+ depth levels, support/resistance detection, liquidity clusters, buying/selling pressure calculation
- **Trend Analysis**: Direction and strength detection with EMA, RSI, ADX, price structure analysis
- **Volume Analysis**: Buy/sell volume split, CVD (Cumulative Volume Delta), spike detection, tape reading
- **Whale Detection**: Large order detection in book and trades, bias analysis, wall detection
- **Terminal UI**: Hacker-themed TUI with live auto-refresh, ASCII charts, colored panels
- **JSON Export**: Full analysis snapshot in JSON format
- **Rust Performance**: Optional Rust engine for high-performance calculations
- **Windows Executable**: Single .exe file with PyInstaller
